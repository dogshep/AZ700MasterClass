# Exam objectives

## Domains

- Design, implement, and manage hybrid networking
- Design and implement core networking infrastructure
- Design and implement routing
- Design and implement private access to Azure services
- Design and implement load balancing and application delivery
- Design and implement network security
- Design and implement monitoring and troubleshooting

## Study focus

Treat Azure as a programmable network fabric. The exam expects you to know the control plane, data plane, the default routing model, and when to use a service such as Azure Firewall, Application Gateway, or Front Door.
