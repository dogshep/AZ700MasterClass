# Study plan

## 30-day plan

- Days 1–7: VNets, subnets, routing, NSGs, Azure Firewall
- Days 8–14: Private Link, ExpressRoute, Virtual WAN, load balancing
- Days 15–21: Front Door, Application Gateway, monitoring, and security
- Days 22–27: Automation with Bicep, CLI, PowerShell, and labs
- Days 28–30: Timed practice exams and final review

## 14-day plan

- Days 1–3: Core connectivity and routing
- Days 4–6: Security and hybrid networking
- Days 7–9: Application delivery and monitoring
- Days 10–12: Automation and troubleshooting
- Days 13–14: Review and mock exam

## Weekend cram

- Saturday: Review all comparison tables and flashcards
- Sunday: Complete a timed practice set and inspect weak domains

## One-week review

- Revisit the exam cram guide and revisit every wrong answer
- Rebuild the packet path for each service from memory

## Exam day checklist

- Confirm portal access if needed
- Review the naming conventions and resource relationships
- Bring a calm mindset and a plan for the first 15 minutes
